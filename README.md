# Pokemon TCG Trend Scanner

Internal-only English Pokemon TCG trend and arbitrage scanner.

## Scope
- English singles only
- TCGplayer US for baseline pricing
- eBay US for active listing signals
- Daily snapshots
- Internal decision support for flips and holds

## Stack
- Node.js + TypeScript
- Postgres
- CSV/Markdown reports first
- React/Next dashboard later

## Planned features
- Daily TCGplayer snapshots
- Daily eBay aggregate snapshots
- Trend score
- Local arbitrage score
- Historical price and inventory tracking

## Run later
This repo is intentionally scaffolded for manual setup first and Codex implementation second.
